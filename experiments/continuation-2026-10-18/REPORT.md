# Fly Brain — 连续学习复核与实验包（2026-10-18）

## 结论

**原版果蝇完整脑尚未通过学习能力验收；本包不是成功训练后的游戏模型。** 这是接续旧 V5 备份的、可复现的边界神经训练与诊断实验。已在 CPU 上实际执行，保留完整失败结果。独立的完整脑图 `graph.npz`（739,883,106 字节）**不在此包中**。

本轮从 2026-10-11 的 V5 备份恢复。源代码对应冻结提交 `3fdac042eb8ba18d04365b9124608d7441b8345e`，但本轮重放数据来自当时较早的 `learning-feedback-anchor-s1101-v1`；**不等同于** V5 中最终选中的 F82 神经网络检查点，更不是 2026-10-17 尚未归档的 2,600 次搜索状态。两种历史结果不得直接当成同一起点比较。

## 为什么当前还没学会

两段连续 100 ms 的同一 RGB 输入，仍易导致不同的整数脉冲计数和相互冲突的左/前/右动作。训练不能只看损失或单窗口正确率；完整脑重放的返回状态和延迟队列决定第二窗口。

**重放模型的真实来源：** 存档完整脑提取的外部释放序列、三个视觉中继神经元、左右两个转向运动神经元，以及已有的 8,476 条输入增益。五细胞内部反馈按原本规则逐毫秒计算，外围神经释放量在训练时固定不变；两个前进神经元计数也使用父模型实测值。此近似能在**原始参数点**逐毫秒完全复现两窗脉冲与状态，但**改变参数后不能保证与完整循环网络等价**。

### 上游信息是否可区分？

额外的**离线** Ridge 分类器只使用已保存的上游释放特征、用 TRAIN 分组交叉验证选 alpha：

- 前100ms 上游释放特征：开发验证 24/24 正确；TRAIN 分组CV平均47/48正确。
- 两个窗口上游释放特征：开发验证24/24正确；TRAIN 分组CV平均47/48正确。
- 五细胞两窗计数：开发验证20/24正确；TRAIN 分组CV平均40/48正确。

**重要边界：这些外部线性读出没有被安装到果蝇模型，也没有参与贪吃蛇决策。** 它们只说明这批样本的记录信号含有可解码的类别信息，不能据此声称原始模型学习成功或可以闭环控制游戏。小样本、pose重叠和此前反复诊断限制了推广性。

## 如何运行

在本包根目录安装 Python（本次实际环境 Python 3.13.5，Torch 2.10.0+cpu，NumPy 2.3.5，scikit-learn），运行：

```bash
python -m pip install torch numpy scikit-learn pytest
python -m pytest test_continuation.py -q

# 重新跑原方案A（选择新的结果目录）
python continue_conditional_experiment.py --source . --output results/repeat-A --steps 12 --lr 0.005 --temporal-weight 0

# 重新跑方案B
python continue_conditional_experiment.py --source . --output results/repeat-B --steps 16 --lr 0.002 --temporal-weight 0.4

# 41个预先固定的 TRAIN 插值点，先确定训练点才读取开发验证
python sweep_continuation.py --source . --proposal results/experiment-01/conditional-selected-parameters.npz --output results/repeat-sweep

# 单独进行离线信息可分性诊断
python diagnose_visual_separability.py --source . --output results/repeat-separability
```

所有输出目录都必须此前不存在。代码不会读取任何封存最终测试样本，不会修改原始权重，也不会上传任何文件。数据源在 `runtime/learning-feedback-anchor-s1101-v1/`。

本轮 CPU 上执行的7项专项测试全部通过；重复运行 A 的12步更新，选中的参数数组和开发验证硬动作与首次执行**完全一致**。

## 哪些东西还不能做 / 验收要求

本环境没有完整图 `graph.npz`，也没有可连接的用户 GPU 设备；无法对训练后的候选重新运行 166,700 个神经元及 25,582,938 条连接。**不能把五细胞固定外围回放视为完整脑神经学习，也不能把外置线性分类器当作生物脑改进。**

要让项目真正证明“能学习”，下一步必须：

1. 在恢复了完整图的同一源码与模型身份上，把候选现有突触增益安装到原连接中（**仅在独立实验副本中**）；重新从RGB运行全脑两个连续100ms窗口，原解码器和其他神经元保持原样。
2. 用 TRAIN 接受或拒绝实际更新；开发验证选择检查点，保持 6 项类别召回和两窗均衡准确率逐项记录。原学习门要求每窗 BA ≥80%，每类召回 ≥75%，不能只用合并窗口或单一类别。
3. 满足验证门后再冻结超参数，做至少 3 个训练种子、相同预算的乱标签及未训练对照、封存图像的最终测试、正常12×12连续贪吃蛇闭环游戏，并报告食物数、碰撞、动作分布与置信区间。
4. 当前观察表明把训练限制在最后 5 个细胞容易产生时序补偿，优先研究包含真实回流的 200ms 梯度、行为奖励的时间差分/资格迹，或扩大原有视觉-运动路径的可塑范围。任何改变视觉采样范围或动作解码规则，需独立版本和原始基线对照。

V5 完整脑已保存的历史结果参见上次独立备份：F82 验证两窗62.5%/83.33%；其 TRAIN-last EA921 接受一次参数更新，而最终验证选中的参数仍为 F82。本轮没有提升这一完整脑指标的证据。

## 文件清单

- `continue_conditional_experiment.py`：使用现有两个参数向量的12/16步监督诊断训练；有严格原始基线检查和训练集硬动作选模。
- `sweep_continuation.py`：41点插值筛选，不使用验证集选候选。
- `diagnose_visual_separability.py`：离线诊断，不接入神经动作解码。
- `test_continuation.py`：基线、延迟状态、参数边界、候选重载和数据分离测试。
- `files/`：重放所需原始软件模块，非完整原始仓库。
- `runtime/`：本轮来源完整脑存档的边界脉冲和元数据，不含完整图。
- `results/`：训练轨迹、验证收据、参数档案、离线分类报告及重复运行凭据。

**GitHub 主仓库未修改，也没有任何模型声称已学会。**
